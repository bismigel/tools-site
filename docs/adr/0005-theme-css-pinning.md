# ADR-0005 — theme CSS: pinned submodule + copied palette + committed output

Date: 2026-11-12 · Status: accepted

## Context

The visual identity lives in `ciceleywebsite`: theme `CaiJimmy/hugo-theme-stack` v4.0.3 plus
`assets/scss/custom.scss` (the rose palette). This repo must look identical, and the two repos
release independently.

Options considered:

| Option | Mechanism | Problem |
| --- | --- | --- |
| A | serve `https://ciceley.cc/scss/style.min.<hash>.css` | fingerprint changes per blog build; a runtime dependency on another deploy |
| B | git submodule of the whole `ciceleywebsite` | a whole site as a submodule for one file |
| C | vendor the compiled CSS only | opaque blob; retheming the blog silently desyncs |
| D | submodule the **theme** + copy `custom.scss`, compile here, commit output | one file to copy on retheme; a build step |

## Decision

**D**, with a CI drift check and a post-compile assertion.

- `theme/hugo-theme-stack` — submodule pinned to the same tag as the blog.
- `theme/site-scss/custom.scss` — byte-for-byte copy of the blog's file, with a comment naming its
  source and the commit it was taken from.
- `theme/tools.css` — generated by `make css` (dart-sass; the theme's `@import "custom.scss"` is
  removed by `sed`, ours is appended so it still wins the cascade), committed.
- Assertions: the output must contain `--rose-500` and `--accent-color`; CI fails if regeneration
  changes the file.

## Reasons

- No runtime coupling: the stylesheet ships inside the image.
- Reviewable: a retheme shows up as a diff of `tools.css` in a PR.
- Deterministic: no `@import` resolution guesswork, no Hugo dependency at runtime, no network at build.

## Costs (accepted)

- A copy that must be refreshed on retheme (mitigated by the assertion + the AGENTS.md rule).
- `tools.css` (~58 kB) lives in git. Acceptable: it is generated, compressed, and diffed rarely.

## Rejected

- A: silent 404/restyle on someone else's deploy.
- B: submodule weight for one file.
- C: no way to see *what* changed when the blog changes.
